2. Database location:
   In AMSFF database, the recommended location for GIOLIB045 is:  <AMSFF_Root_Dir>/LIBS/GPDK045/<giolib045_vx.x>
   Then, create a symbolic link 'giolib045' to a specific GIOLIB045 version.
   

3. Pad and IO cell info:
   Please refer to this text view: giolib045/Info/ReadMe 
   
4. Process technology: GPDK045 (Cadence Generic Process Kit, 45nm node).
   Recommended version: gpdk045_v4.0 or later versions.
